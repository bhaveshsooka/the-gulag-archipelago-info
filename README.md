# The Gulag Archipelago

This repository contains code to generate a static site with information and metadata about the audiobook The Gulag Archipelago By Aleksandr Solzhenitsyn published by Blackstone Audio and Narrated by Frederick Davidson. The reading is uploaded to YouTube

## Getting Started

The website was built using [MkDocs](https://www.mkdocs.org/) using a [Torillic](https://github.com/bhaveshsooka/torillic) theme, within a Python3 virtual environment.

The website is hosted on GitHub Pages, and is automatically updated whenever I make a change to the code or data.

## Running the site

1. Clone the repository: `git clone https://github.com/bhaveshsooka/the-gulag-archipelago-info.git`

2. Navigate to the repository directory: `cd the-gulag-archipelago-info`

3. Create a virtual environment: `python3 -m venv venv`

4. Activate the virtual environment: `source venv/bin/activate`

5. Install dependencies: `python3 -m pip install -r requirements.txt`

6. Run the development server: `mkdocs serve`

7. Build the static site: `mkdocs build`
